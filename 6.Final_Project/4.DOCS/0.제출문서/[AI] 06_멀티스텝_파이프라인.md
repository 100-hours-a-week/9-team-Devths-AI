## Why: 우리 서비스에 왜 필요한가?

Devths AI 서비스는 **이력서 분석 → 채용공고 매칭 → 모의 면접 → 일정 관리**를 하나의 챗봇으로 처리합니다.

**단순 LLM 호출의 한계:**
- 단일 프롬프트로 복잡한 작업 처리 불가
- 면접처럼 상태 관리가 필요한 대화 불가능
- 외부 시스템(캘린더) 연동 어려움

**멀티스텝 파이프라인 도입 이유:**
- **LangChain**: RAG 체인, 프롬프트 관리
- **LangGraph**: 상태 기반 복잡한 워크플로우 (면접)
- **Tool Calling**: 캘린더 CRUD 등 외부 시스템 연동

### 마스킹 파이프라인 (V1 → V2 → V3 진화)

#### V1 (MVP): VLM 단독 처리

```
POST /ai/masking/draft
  ↓
Request: { "s3_key": "board/123/image.jpg" }
  ↓
VLM (Gemini Vision)
  ↓
Prompt: 개인정보 좌표 추출 (JSON 형식)
  - 이름 (name)
  - 전화번호 (phone)
  - 이메일 (email)
  - 얼굴 (face)
  ↓
마스킹 처리 (블러/모자이크)
  ↓
Response: { "task_id": "uuid" }
```

**특징:**
- ✅ 간단한 구조 (빠른 출시)
- ⚠️ 한글 인식 정확도 낮음 (85-90%)
- ⚠️ 좌표 정확도 낮음

---

#### V2 (고도화): CLOVA OCR + YOLO 병렬 처리

```
POST /ai/masking/draft
  ↓
Request: { "s3_key": "board/123/image.jpg" }
  ↓
┌─────────────────────────────────┐
│ 병렬 처리 (Parallel Processing) │
├─────────────────────────────────┤
│                                 │
│ ┌─────────────┐  ┌───────────┐ │
│ │ CLOVA OCR   │  │   YOLO    │ │
│ │ (텍스트 좌표)│  │ (얼굴 좌표)│ │
│ └──────┬──────┘  └─────┬─────┘ │
│        │                │       │
│        └────────┬───────┘       │
│                 ↓               │
│         좌표 병합 + 필터링       │
│         (이름, 전화번호, 이메일) │
└─────────────────────────────────┘
  ↓
마스킹 처리 (블러/모자이크)
  ↓
S3 업로드 (masked_s3_key)
  ↓
Response: { "task_id": "uuid" }
```

**특징:**
- ✅ **한글 인식 정확도 향상** (95%+, CLOVA OCR)
- ✅ **얼굴 탐지 정확도 향상** (98%, YOLO)
- ✅ **병렬 처리로 속도 개선** (1-2초)
- ✅ **비용 절감** (CLOVA 무료 티어 + YOLO 자체 운영)

### RAG 검색 워크플로우

#### 전체 흐름: 데이터 저장 → 검색 → LLM 응답

```
┌──────────────────────────────────────────────────────────┐
│              [1단계] 데이터 저장 (Indexing)               │
└──────────────────────────────────────────────────────────┘

POST /ai/text/extract (이력서/포트폴리오/채용공고)
  ↓
OCR/텍스트 추출
  ↓
텍스트 청킹 (512 tokens)
  ↓
Embedding Model (Gemini text-embedding-004)
  ↓
VectorDB (ChromaDB) 저장
  - Collection: resumes, job_postings, interview_feedback


┌──────────────────────────────────────────────────────────┐
│              [2단계] RAG 검색 (Retrieval)                 │
└──────────────────────────────────────────────────────────┘

POST /ai/chat (mode: general | interview_question)
  ↓
┌─────────────────────────────────┐
│  쿼리 임베딩                     │
│  - Gemini text-embedding-004    │
│  - 768차원 벡터 생성             │
└─────────────────────────────────┘
  ↓
┌─────────────────────────────────┐
│  Hybrid Search                  │
│  ┌───────────────────────────┐  │
│  │ BM25 (키워드 30%)         │  │
│  │ - 정확한 용어 매칭        │  │
│  └───────────────────────────┘  │
│  ┌───────────────────────────┐  │
│  │ Vector Search (의미 70%)  │  │
│  │ - 코사인 유사도           │  │
│  └───────────────────────────┘  │
│                                 │
│  → Top 20개 문서 추출           │
└─────────────────────────────────┘
  ↓
┌─────────────────────────────────┐
│  Reranker (Cohere Rerank)       │
│  - Top 20 → Top 3로 정제        │
│  - 정확도 10-15% 향상           │
└─────────────────────────────────┘
  ↓
검색된 컨텍스트 (Top 3)


┌──────────────────────────────────────────────────────────┐
│           [3단계] 프롬프트 증강 (Augmentation)            │
└──────────────────────────────────────────────────────────┘

┌─────────────────────────────────┐
│  프롬프트 구성                   │
│                                 │
│  [페르소나]                     │
│  당신은 커리어 코치 AI입니다.   │
│                                 │
│  [컨텍스트]                     │
│  {검색된 이력서 내용}           │
│  {이전 분석 결과}               │
│                                 │
│  [사용자 질문]                  │
│  내 이력서 분석해줘             │
└─────────────────────────────────┘
  ↓
LLM (Gemini 2.0-flash)
  ↓
SSE 스트리밍 응답
```

## 3. 구현 코드 (의사코드 포함) ✅

### 3-1. LangGraph 면접 워크플로우

```python
from langgraph.graph import StateGraph, END
from typing import TypedDict, List

# State 정의
class InterviewState(TypedDict):
    session_id: str
    user_id: str
    questions: List[dict]
    answers: List[dict]
    current_index: int
    status: str  # "in_progress" | "completed"

# 노드 함수들
def generate_question(state: InterviewState) -> InterviewState:
    """RAG 기반 질문 생성 (mode: interview_question)"""
    context = vectordb.search(state['user_id'])
    question = llm.invoke(f"컨텍스트: {context}\n질문 생성")
    state['questions'].append({"question": question, "type": "main"})
    return state

def save_qa(state: InterviewState) -> InterviewState:
    """Q&A 저장"""
    db.save_qa(state['session_id'], state['questions'][-1], state['answers'][-1])
    state['current_index'] += 1
    return state

def check_condition(state: InterviewState) -> str:
    """종료 조건 확인"""
    if state['current_index'] >= 5:
        return "generate_report"
    if state['status'] == "user_ended":
        return "generate_report"
    return "generate_question"

def generate_report(state: InterviewState) -> InterviewState:
    """면접 리포트 생성 (mode: interview_report)"""
    # context 배열 구성: [{question, answer}, ...]
    context = [
        {"question": q["question"], "answer": a["answer"]}
        for q, a in zip(state['questions'], state['answers'])
    ]

    # POST /ai/chat with mode: interview_report
    report = llm.invoke({
        "mode": "interview_report",
        "context": context,
        "message": "면접 결과를 분석해주세요"
    })

    state['status'] = "completed"
    return state

# 그래프 구성
workflow = StateGraph(InterviewState)

workflow.add_node("generate_question", generate_question)
workflow.add_node("save_qa", save_qa)
workflow.add_node("generate_report", generate_report)

workflow.set_entry_point("generate_question")
workflow.add_edge("generate_question", "save_qa")
workflow.add_conditional_edges(
    "save_qa",
    check_condition,
    {
        "generate_question": "generate_question",
        "generate_report": "generate_report"
    }
)
workflow.add_edge("generate_report", END)

app = workflow.compile()
```

### 3-2. RAG Hybrid Search + Reranker

```python
from langchain.retrievers import EnsembleRetriever
from langchain_community.retrievers import BM25Retriever

async def rag_search_pipeline(
    query: str,
    user_id: str,
    collection: str = "resumes",
    k: int = 3
):
    """Hybrid Search + Reranker RAG 파이프라인"""

    # 1. 쿼리 임베딩
    query_embedding = await gemini_embedding.embed_query(query)

    # 2. Hybrid Search (BM25 + Vector)
    bm25_retriever = BM25Retriever.from_documents(
        documents=vectordb.get_documents(collection),
        k=20
    )

    vector_retriever = vectordb.as_retriever(
        search_type="similarity",
        search_kwargs={
            "k": 20,
            "filter": {"user_id": user_id}
        }
    )

    # Ensemble Retriever (BM25 30% + Vector 70%)
    ensemble_retriever = EnsembleRetriever(
        retrievers=[bm25_retriever, vector_retriever],
        weights=[0.3, 0.7]
    )

    # 3. Top 20 검색
    docs = await ensemble_retriever.aget_relevant_documents(query)

    # 4. Reranker (Top 20 → Top 3)
    reranked = await cohere_rerank(
        query=query,
        documents=docs,
        top_n=k
    )

    # 5. 컨텍스트 구성
    context = "\n\n".join([doc.page_content for doc in reranked])

    # 6. 프롬프트 증강
    augmented_prompt = f"""
[페르소나]
{CAREER_COACH_PERSONA}

[컨텍스트]
{context}

[사용자 질문]
{query}

위 컨텍스트를 참고하여 개인화된 답변을 제공하세요.
"""

    # 7. LLM 호출 (SSE 스트리밍)
    response = await llm.ainvoke(augmented_prompt)

    return response
```

```python
import asyncio
from typing import List, Dict

async def masking_pipeline_v3(s3_key: str) -> dict:
    """CLOVA OCR + YOLO 병렬 처리

    POST /ai/masking/draft 내부 로직
    """

    # 1. S3에서 이미지 다운로드
    image_url = await s3_client.get_presigned_url(s3_key)

    # 2. 병렬 처리
    ocr_task = asyncio.create_task(clova_ocr(image_url))
    yolo_task = asyncio.create_task(yolo_detect(image_url))

    ocr_result, yolo_result = await asyncio.gather(ocr_task, yolo_task)

    # 3. 좌표 통합
    all_coordinates = []

    # OCR 좌표 (이름, 전화번호, 이메일)
    for item in ocr_result['fields']:
        if item['type'] in ['name', 'phone', 'email']:
            all_coordinates.append({
                "type": item['type'],
                "coordinates": item['boundingPoly'],
                "confidence": item['confidence']
            })

    # YOLO 좌표 (얼굴)
    for face in yolo_result['detections']:
        all_coordinates.append({
            "type": "face",
            "coordinates": face['bbox'],
            "confidence": face['confidence']
        })

    # 4. 마스킹 처리
    masked_image = apply_masking(image_url, all_coordinates)

    # 5. S3 업로드
    masked_s3_key = await s3_client.upload(masked_image)

    return {
        "masked_s3_key": masked_s3_key,
        "detected_pii": all_coordinates
    }
```

```python
def add_schedule(title: str, datetime: str) -> str:
```
