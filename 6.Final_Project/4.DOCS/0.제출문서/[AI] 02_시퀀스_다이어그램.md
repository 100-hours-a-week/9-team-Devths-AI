## 1. 대화창 생성

**Backend Endpoint:** `POST /api/chat/rooms`

> AI Server 호출 없음 (Backend만 처리)

```mermaid
sequenceDiagram
    participant User
    participant Web
    participant Backend

    User->>Web: 1. 챗봇 버튼 클릭
    Web->>Backend: 2. 대화창 생성 요청
    Backend->>Backend: 3. 대화창 생성 (PostgreSQL)
    Backend-->>Web: 4. room_id 반환
    Web-->>User: 5. 대화창 출력
```

## 2. 이력서/채용공고 텍스트 추출 + 분석

**사용 AI API:**
- `POST /ai/text/extract` - 텍스트 추출 + 임베딩 저장 + 분석 (비동기)
- `GET /ai/task/{task_id}` - 작업 상태 폴링

> **핵심:** resume + job_posting을 함께 전송하면 OCR → 임베딩 → 분석 리포트까지 한번에 처리

```mermaid
sequenceDiagram
    participant User
    participant Web
    participant Backend
    participant S3
    participant AIServer
    participant VectorDB
    participant LLM

    User->>Web: 1. 이력서 + 채용공고 첨부

    alt 파일 업로드
        Web->>Backend: 2. Presigned URL 요청
        Backend->>S3: 3. Presigned URL 생성
        S3-->>Backend: 4. Presigned URL 반환
        Backend-->>Web: 5. Presigned URL 전달
        Web->>S3: 6. 파일 직접 업로드
        S3-->>Web: 7. 업로드 완료 (s3_key)
    end

    Web->>Backend: 8. 분석 요청 (resume + job_posting)
    Backend->>AIServer: 9. POST /ai/text/extract
    Note over Backend,AIServer: Request Body:<br/>model: "gemini"<br/>user_id: 12<br/>resume: {file_id, s3_key, file_type, text}<br/>job_posting: {file_id, s3_key, file_type, text}

    AIServer-->>Backend: 10. 202 Accepted (task_id)

    rect rgb(240, 248, 255)
        Note over AIServer,LLM: [AI Server 내부 비동기 처리]
        alt resume가 파일인 경우
            AIServer->>AIServer: 11a. resume OCR
        end
        alt job_posting이 파일인 경우
            AIServer->>AIServer: 11b. job_posting OCR
        end
        AIServer->>VectorDB: 12. 임베딩 생성 + 저장
        VectorDB-->>AIServer: 13. 저장 완료
        AIServer->>LLM: 14. 분석 리포트 생성 프롬프트
        LLM-->>AIServer: 15. 분석 결과
    end

    loop 폴링 (1초 간격)
        Backend->>AIServer: GET /ai/task/{task_id}
        AIServer-->>Backend: status: processing
    end

    AIServer-->>Backend: 16. 완료 응답
    Note over Backend,AIServer: Response:<br/>task_id, room_id, status: completed<br/>result.resume_ocr<br/>result.job_posting_ocr<br/>result.resume_analysis<br/>result.posting_analysis

    Backend->>Backend: 17. PostgreSQL에 OCR 텍스트 저장
    Backend-->>Web: 18. 분석 결과 응답
    Web-->>User: 19. 분석 리포트 출력
```

### Request/Response 예시

**Request (POST /ai/text/extract):**
```json
{
    "model": "gemini",
    "room_id": 23,
    "user_id": 12,
    "resume": {
        "file_id": 23,
        "s3_key": "https://bucket.s3.amazonaws.com/users/12/resume/abc123.pdf",
        "file_type": "application/pdf",
        "text": null
    },
    "job_posting": {
        "file_id": null,
        "s3_key": null,
        "file_type": null,
        "text": "카카오 백엔드 개발자 채용\n자격요건: Java, Spring..."
    }
}
```

**Response (GET /ai/task/{task_id} - 완료 시):**
```json
{
    "task_id": 12,
    "room_id": 32,
    "status": "completed",
    "result": {
        "success": true,
        "resume_ocr": "이력서 OCR 텍스트...",
        "job_posting_ocr": "채용공고 OCR 텍스트...",
        "resume_analysis": {
            "strengths": ["React 숙련도", "프로젝트 경험"],
            "weaknesses": ["백엔드 경험 부족"],
            "suggestions": ["Spring 학습 권장"]
        },
        "posting_analysis": {
            "company": "카카오",
            "position": "백엔드 개발자",
            "required_skills": ["Java", "Spring", "MySQL"],
            "preferred_skills": ["Docker", "Kubernetes"]
        }
    }
}
```

## 3. 일반 채팅 (RAG)

**사용 AI API:**
- `POST /ai/chat` - context.mode: "general" (스트리밍 SSE)

> **핵심:** VectorDB에서 관련 컨텍스트 검색 후 LLM 응답 생성

```mermaid
sequenceDiagram
    participant User
    participant Web
    participant Backend
    participant AIServer
    participant VectorDB
    participant LLM

    User->>Web: 1. "이력서 작성 팁 알려줘"
    Web->>Backend: 2. 메시지 전송

    Backend->>AIServer: 3. POST /ai/chat
    Note over Backend,AIServer: mode: "general"<br/>message: "이력서 작성 팁 알려줘"<br/>history: [이전 대화...]

    AIServer->>VectorDB: 4. 관련 컨텍스트 검색 (RAG)
    VectorDB-->>AIServer: 5. 검색 결과
    AIServer->>LLM: 6. 프롬프트 + 컨텍스트
    LLM-->>AIServer: 7. 응답 생성 (스트리밍)

    AIServer-->>Backend: 8. SSE 스트리밍 응답
    Backend-->>Web: 9. 실시간 응답 전달
    Web-->>User: 10. 타이핑 효과로 출력
```

### Request/Response 예시

**Request:**
```json
{
    "model": "gemini",
    "room_id": 1,
    "user_id": 12,
    "message": "이력서 작성 팁 알려줘",
    "session_id": null,
    "context": {
        "mode": "general",
        "resume_ocr": null,
        "job_posting_ocr": null,
        "interview_type": null,
        "question_count": null
    }
}
```

**Response (SSE):**
```json
{
    "success": true,
    "mode": "general",
    "response": "이력서 작성 팁을 알려드릴게요..."
}
```

## 4. 모의면접 - 질문 생성

**사용 AI API:**
- `POST /ai/chat` - context.mode: "interview_question" (스트리밍 SSE)

> **핵심:** 이력서 + 채용공고 기반 면접 질문/꼬리질문 생성

```mermaid
sequenceDiagram
    participant User
    participant Web
    participant Backend
    participant AIServer
    participant VectorDB
    participant LLM

    Note over User,LLM: [면접 모드 시작]

    User->>Web: 1. 면접 시작 버튼 클릭
    Web->>Backend: 2. 면접 세션 생성
    Backend->>Backend: 3. session_id 생성 (DB 저장)
    Backend-->>Web: 4. session_id 반환
    Web-->>User: 5. "면접 모드입니다" + 유형 선택 버튼

    Note over User,LLM: [첫 질문 생성]

    User->>Web: 6. 기술 면접 선택
    Web->>Backend: 7. 첫 질문 요청
    Backend->>AIServer: 8. POST /ai/chat
    Note over Backend,AIServer: mode: "interview_question"<br/>interview_type: "technical"<br/>resume_ocr: "OCR 내용"<br/>job_posting: "OCR 내용"<br/>question_count: 0

    AIServer->>VectorDB: 9. 이력서/피드백 검색 (RAG)
    VectorDB-->>AIServer: 10. 관련 컨텍스트
    AIServer->>LLM: 11. 질문 생성 프롬프트
    LLM-->>AIServer: 12. 면접 질문

    AIServer-->>Backend: 13. 질문 응답
    Backend-->>Web: 14. 질문 전달
    Web-->>User: 15. 첫 질문 출력

    Note over User,LLM: [Q&A 반복 - 최대 5개]

    loop question_count < 5
        User->>Web: 16. 답변 입력
        Web->>Backend: 17. 답변 저장
        Backend->>Backend: 18. Q&A DB 저장

        Web->>Backend: 19. 꼬리질문 요청
        Backend->>AIServer: 20. POST /ai/chat
        Note over Backend,AIServer: mode: "interview_question"<br/>question_count: N

        AIServer->>LLM: 21. 꼬리질문 생성
        LLM-->>AIServer: 22. 꼬리질문
        AIServer-->>Backend: 23. 질문 응답
        Backend-->>Web: 24. 꼬리질문 전달
        Web-->>User: 25. 꼬리질문 출력
    end
```

### Request/Response 예시

**Request (면접 질문 생성):**
```json
{
    "model": "gemini",
    "room_id": 1,
    "user_id": 12,
    "message": "기술 면접 질문 생성해줘",
    "session_id": 23,
    "context": {
        "mode": "interview_question",
        "resume_ocr": "OCR 내용",
        "job_posting_ocr": "OCR 내용",
        "interview_type": "technical",
        "question_count": 0
    }
}
```

**Response:**
```json
{
    "success": true,
    "mode": "interview_question",
    "response": "React와 Vue의 차이점에 대해 설명해주세요.",
    "interview_type": "technical"
}
```

## 5. 모의면접 - 리포트 생성

**사용 AI API:**
- `POST /ai/chat` - 면접 종료 시 평가 리포트 생성 (스트리밍 SSE)

> **핵심:** 전체 Q&A 히스토리 기반 종합 평가 및 피드백

```mermaid
sequenceDiagram
    participant User
    participant Web
    participant Backend
    participant AIServer
    participant VectorDB
    participant LLM

    Note over User,LLM: [면접 종료 - 5개 완료 또는 수동 종료]

    alt 5개 질문 완료
        Web->>Web: 1a. 자동 종료
    else 수동 종료
        User->>Web: 1b. 면접 종료 버튼
    end

    Web-->>User: 2. "면접이 종료되었습니다"

    Web->>Backend: 3. 리포트 요청
    Backend->>Backend: 4. session_id로 Q&A 조회
    Backend->>AIServer: 5. POST /ai/chat (리포트)
    Note over Backend,AIServer: session_id: "interview_001"<br/>context: [{question, answer}, ...]

    AIServer->>VectorDB: 6. 유사 면접 결과 검색
    VectorDB-->>AIServer: 7. 참조 데이터
    AIServer->>LLM: 8. 리포트 생성 프롬프트
    LLM-->>AIServer: 9. 평가 리포트 (스트리밍)

    AIServer-->>Backend: 10. 리포트 응답
    Backend->>Backend: 11. 세션 상태 업데이트 (completed)
    Backend-->>Web: 12. 리포트 전달 (스트리밍)
    Web-->>User: 13. 리포트 출력
    Web->>Web: 14. 일반 대화 모드로 복귀
```

### Request/Response 예시

**Request (면접 리포트):**
```json
{
    "model": "gemini",
    "room_id": 1,
    "user_id": 12,
    "session_id": 23,
    "context": [
        {
            "question": "~~",
            "answer": "...."
        }
    ]
}
```

**Response:**
```json
{
    "success": true,
    "mode": "interview_report",
    "report": {
        "evaluations": [
            {
                "question": "React의 Virtual DOM이 무엇인가요?",
                "answer": "실제 DOM과 비교해서 변경된 부분만 업데이트하는 거예요",
                "good_points": ["Virtual DOM의 기본 개념을 잘 이해하고 있음"],
                "improvements": ["Reconciliation 알고리즘 설명 추가하면 좋음"]
            }
        ],
        "strength_patterns": ["기술 개념에 대한 이해도가 높음"],
        "weakness_patterns": ["심화 개념 설명이 부족함"],
        "learning_guide": ["React 심화 개념 학습 (Fiber, Concurrent Mode)"]
    }
}
```

## 6. 캘린더 일정 파싱

**사용 AI API:**
- `POST /ai/calendar/parse` - 일정 정보 추출 (동기)

> 챗봇이 아닌 **캘린더 모달**에서 파일 분석 시 사용

```mermaid
sequenceDiagram
    participant User
    participant Web
    participant Backend
    participant AIServer
    participant LLM
    participant GoogleCalendar

    User->>Web: 1. 캘린더 → 일정 추가 클릭
    User->>Web: 2. 채용공고 파일/텍스트 첨부
    Web->>Backend: 3. 일정 파싱 요청

    Backend->>AIServer: 4. POST /ai/calendar/parse
    Note over Backend,AIServer: s3_key: "https://s3.../job.png"<br/>or text: "카카오 채용..."

    alt 파일인 경우
        AIServer->>AIServer: 5. OCR 처리
    end

    AIServer->>LLM: 6. 일정 추출 프롬프트
    LLM-->>AIServer: 7. 추출된 일정 JSON
    AIServer-->>Backend: 8. 일정 정보 반환
    Backend-->>Web: 9. 일정 미리보기
    Web-->>User: 10. 폼에 자동 채워넣기

    User->>Web: 11. 확인/수정 후 저장
    Web->>Backend: 12. 일정 등록 요청
    Backend->>GoogleCalendar: 13. 이벤트 생성
    GoogleCalendar-->>Backend: 14. event_id 반환
    Backend->>Backend: 15. MongoDB에 메타데이터 저장
    Backend-->>Web: 16. 등록 완료
    Web-->>User: 17. 완료 메시지
```

### Request/Response 예시

**Request:**
```json
{
    "s3_key": "https://s3.../job_posting.png",
    "text": null
}
```

또는

```json
{
    "s3_key": null,
    "text": "카카오 백엔드 개발자 채용\n서류마감: 2026-01-15\n코딩테스트: 2026-01-20..."
}
```

**Response (200 OK):**
```json
{
    "success": true,
    "company": "카카오",
    "position": "백엔드 개발자",
    "schedules": [
        { "stage": "서류 마감", "date": "2026-01-15", "time": null },
        { "stage": "코딩테스트", "date": "2026-01-20", "time": "14:00" },
        { "stage": "1차 면접", "date": "2026-01-25", "time": null }
    ],
    "hashtags": ["#카카오", "#백엔드", "#신입"]
}
```

## 7. 게시판 첨부파일 마스킹

**사용 AI API:**
- `POST /ai/masking/draft` - 1차 개인정보 마스킹 (비동기)
- `GET /ai/task/{task_id}` - 작업 상태 폴링

> 게시글 작성 시 첨부파일에서 개인정보 자동 마스킹

```mermaid
sequenceDiagram
    participant User
    participant Web
    participant Backend
    participant S3
    participant AIServer
    participant LLM

    Note over User,LLM: [1단계: 첨부파일 업로드 + AI 마스킹]

    User->>Web: 1. 게시글 작성 중 파일 첨부
    Web->>Backend: 2. Presigned URL 요청
    Backend->>S3: 3. Presigned URL 생성
    S3-->>Backend: 4. Presigned URL 반환
    Backend-->>Web: 5. Presigned URL 전달

    Web->>S3: 6. 파일 직접 업로드
    S3-->>Web: 7. 업로드 완료 (s3_key)

    Web->>Web: 8. 마스킹 대기 모달 표시

    Web->>Backend: 9. 마스킹 요청
    Backend->>AIServer: 10. POST /ai/masking/draft
    Note over Backend,AIServer: s3_key: "https://s3.../doc.png"<br/>file_type: "image"<br/>model: "gemini"

    AIServer-->>Backend: 11. 202 Accepted (task_id)

    rect rgb(240, 248, 255)
        Note over AIServer,LLM: [AI Server 내부 처리]
        AIServer->>LLM: 12. VLM으로 PII 좌표 추출
        LLM-->>AIServer: 13. 마스킹 영역 좌표
        AIServer->>AIServer: 14. 이미지 마스킹 처리
        AIServer->>S3: 15. 마스킹 이미지 저장
    end

    loop 폴링
        Backend->>AIServer: GET /ai/task/{task_id}
        AIServer-->>Backend: status: processing
    end

    AIServer-->>Backend: 16. 완료 응답
    Note over Backend,AIServer: masked_url, thumbnail_url<br/>detected_pii: [{type, coordinates, confidence}]

    Backend-->>Web: 17. 마스킹 결과 반환
    Web->>Web: 18. 대기 모달 닫힘
    Web-->>User: 19. 마스킹된 썸네일 표시

    Note over User,Backend: [2단계: 사용자 편집 (선택적) - AI 불필요]

    User->>Web: 20. 편집 버튼 클릭
    Web-->>User: 21. 캔버스 편집 모달
    User->>Web: 22. 마스킹 영역 추가/제거
    User->>Web: 23. 확인

    Web->>Backend: 24. 수정된 좌표 전송
    Backend->>Backend: 25. 좌표 기반 블러 처리 (AI 불필요)
    Backend->>S3: 26. 최종 마스킹 이미지 저장
    Backend-->>Web: 27. 업데이트 완료

    Note over User,Backend: [3단계: 게시글 등록]

    User->>Web: 28. 게시글 등록
    Web->>Backend: 29. 게시글 + 마스킹 파일 URL 등록
    Backend->>Backend: 30. DB 저장
    Backend-->>Web: 31. 등록 완료
    Web-->>User: 32. 완료 메시지
```

### Request/Response 예시

**Request (POST /ai/masking/draft):**
```json
{
    "s3_key": "https://s3.../document.png",
    "file_type": "image",
    "model": "gemini"
}
```

**Response (202 Accepted):**
```json
{
    "task_id": 32,
    "status": "processing"
```
