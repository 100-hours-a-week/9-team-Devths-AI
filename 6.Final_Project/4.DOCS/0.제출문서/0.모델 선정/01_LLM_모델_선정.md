### 1.1 OCR 모델

| 모델명 | 제공사 | 타입 | 비용 | 한국어 지원 | 테스트 상태 |
|--------|--------|------|------|:----------:|:----------:|
| **Gemini VLM** | Google | 상용 API | 무료 (일일한도) | ✅ | ✅ 1순위 (CER 0.08) |
| **EasyOCR** | JaidedAI (OSS) | 로컬 라이브러리 | 무료 | ✅ | ✅ 3순위 (속도 1위) |
| **CLOVA OCR** | Naver | 상용 API | $0.002/페이지 | ✅ | ✅ 2순위 (한글 98.6%) |
| **pytesseract** | Google (OSS) | 로컬 라이브러리 | 무료 | ⚠️ | ❌ 권장안함 (22.9%) |
| **PaddleOCR** | Baidu (OSS) | 로컬 라이브러리 | 무료 | ✅ | 🔄 검토 가능 |

**선정 근거** (상세: [02_OCR_모델_선정.md](./02_OCR_모델_선정.md)):
- **Gemini VLM**: CER 1위 (0.08), 무료 (일일 1,500요청), 문맥 기반 오류 수정
- **EasyOCR**: 속도 1위 (1.8초), 무료, Fallback용
- **CLOVA OCR**: 한글정확도 1위 (98.6%), 유료지만 고정확도 필요시
- **pytesseract**: ❌ 한글정확도 22.9%로 **사용 불가**

### 2.2 채팅 API 모드별 기능

`POST /ai/chat` API는 `context.mode` 파라미터로 다양한 기능을 제공합니다:

| Mode | 기능 | 설명 | 사용 시점 | 기존 API 매핑 |
|------|------|------|----------|-------------|
| **general** | 일반 대화 | 취업 상담, RAG 검색 | 기본 채팅 | `/ai/chat` (기존) |
| **interview_question** | 면접 질문 생성 | 기술/인성 면접 질문 생성 | 면접 모드 시작, 꼬리질문 | `/ai/interview/question` (기존) |
| **interview_report** | 면접 리포트 | 면접 평가 및 피드백 생성 | 면접 종료 시 | `/ai/report` (기존) |

### 2.3 텍스트 추출 API 기능

`POST /ai/text/extract` API는 이력서와 채용공고를 함께 처리합니다:

| 입력 조합 | 처리 내용 | 출력 |
|----------|----------|------|
| **resume + job_posting** | OCR → VectorDB 저장 → 분석 리포트 생성 | OCR 텍스트 + 분석 리포트 |
| **resume만** | OCR → VectorDB 저장 | OCR 텍스트만 (분석 없음) |
| **job_posting만** | OCR → VectorDB 저장 | OCR 텍스트만 (분석 없음) |

> **참고**: 기존 `/ai/analyze` API는 `/ai/text/extract` (resume + job_posting)로 통합됨

### 2.4 보조 AI 기능 (내부 처리)
