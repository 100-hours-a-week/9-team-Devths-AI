## 1. 개요

### 목적
PDF/이미지에서 텍스트를 추출하는 OCR 모델 선정

### 사용 사례
- 이력서 PDF 텍스트 추출
- 포트폴리오 문서 텍스트 추출
- 채용공고 이미지 텍스트 추출

### 핵심 결정
- **1순위 (정확도)**: Gemini VLM - CER 1위 (0.0816), 무료
- **2순위 (한글 특화)**: CLOVA OCR - 한글정확도 1위 (98.6%), 유료
- **3순위 (속도/무료)**: EasyOCR - 속도 1위 (1.8초), 무료
- **Fallback 전략**: EasyOCR → Gemini VLM → CLOVA OCR

## 2. OCR 요구사항

| 요구사항 | 목표 | 우선순위 |
|---------|------|---------|
| **비용** | 월 $0 (무료) | 🔴 매우 높음 |
| **한국어 정확도** | 90% 이상 | 🔴 매우 높음 |
| **처리 속도** | 페이지당 5초 이내 | 🟡 중간 |
| **레이아웃 보존** | 표, 목록 구조 인식 | 🟢 낮음 |

### 비용이 중요한 이유
포트폴리오/이력서의 특성상 **페이지 수가 많음**:
- 이력서: 1~3 페이지
- 포트폴리오: **10~30 페이지**
- PDF 페이지마다 API 호출 필요 → 비용 폭증

## 3. 후보 모델 비교

### 3.1 Gemini VLM ✅ 1순위 (정확도)

**개요**:
- Google의 멀티모달 AI 모델
- 이미지 이해 + OCR + 문맥 분석

**장점**:
- ✅ **CER 1위** (테스트 결과 0.0816)
- ✅ **문맥 기반 오류 자동 수정** (LLM 능력)
- ✅ 레이아웃 이해 (표, 목록 구조)
- ✅ 손글씨 인식 가능
- ✅ **Gemini 3.0 Flash Preview는 저렴!** ($2/M input tokens, 2.5 지원 종료 예정)

**단점**:
- ❌ PDF 페이지마다 API 호출 필요 → 대용량 시 한도 소진 리스크
- ❌ 인터넷 연결 필수
- ❌ 가끔 없는 내용을 지어내는 **Hallucination 위험**
- ❌ 처리 속도가 가장 느림 (3.89초/페이지)

**실제 테스트 성능**:
| 지표 | 결과 |
|------|------|
| CER (Character Error Rate) | **0.0816** 🏆 |
| WER (Word Error Rate) | 0.0522 |
| 한국어 정확도 | **97.4%** |
| 처리 속도 | 3.89초/페이지 |

**Gemini 모델별 비용 및 지원**:

| 모델 | 비용 | 이미지 | PDF | 일일 한도 |
|------|------|--------|-----|----------|
| **Gemini 3.0 Flash Preview** | **$2/M 입력** | ✅ | ✅ | 무제한 |
| Gemini 2.5 Flash (레거시) | 무료 | ✅ | ✅ | 곧 지원 종료 ⚠️ |
| Gemini 1.5 Pro | 유료 | ✅ | ✅ | - |

> 💡 **핵심**: Gemini 3.0 Flash Preview는 이미지/PDF 모두 지원, 한도 없음!
>
> 💰 **비용**: 월 1,000건 (평균 2페이지) = 2M 토큰 × $2 = **$4/월** (매우 저렴)

---

### 3.2 CLOVA OCR (Naver) ✅ 2순위 (한글 특화)

**개요**:
- 네이버의 한국어 특화 OCR 서비스
- 한국어 인식률 업계 최고 수준

**장점**:
- ✅ **한글정확도 1위** (테스트 결과 98.6%)
- ✅ 표/양식 인식 우수
- ✅ 받침, 흘림체, 특수문자 인식 정확
- ✅ "있는 그대로" 읽어내는 순수 OCR 성능 최고
- ✅ AI의 "상상"이 없음 (Hallucination 없음)

**단점**:
- ❌ 페이지당 API 호출 비용 발생
- ❌ 월 100건 무료 후 유료 (General OCR 기준)
- ❌ API 키 발급 및 설정 필요
- ❌ CER은 Gemini보다 높음 (영문/특수문자 포함 시)

**실제 테스트 성능**:
| 지표 | 결과 |
|------|------|
| 한국어 정확도 | **98.6%** 🏆 |
| CER (Character Error Rate) | 0.3047 |
| WER (Word Error Rate) | 0.0694 |
| 처리 속도 | 3.13초/페이지 (API) |

**비용 모델**:
| 서비스 | 무료 | 유료 |
|--------|------|------|
| General OCR | 월 100건 | 3원/건 |
| Document OCR | 월 100건 | 30원/건 |

---

### 3.3 EasyOCR ✅ 3순위 (속도/무료)

**개요**:
- JaidedAI에서 개발한 딥러닝 기반 오픈소스 OCR
- 80개 이상 언어 지원 (한국어 포함)
- PyTorch 기반, GPU 가속 지원

**장점**:
- ✅ 완전 무료 (오픈소스)
- ✅ **속도 1위** (1.8초/페이지)
- ✅ 한국어 인식 우수 (테스트 결과 91.4%)
- ✅ GPU 사용 시 빠른 처리
- ✅ 대량 처리에 적합 (한도 없음)

**단점**:
- ❌ 첫 실행 시 모델 다운로드 필요 (~100MB)
- ❌ Gemini/CLOVA 대비 정확도 낮음
- ❌ CPU에서는 다소 느림

**실제 테스트 성능**:
| 지표 | 결과 |
|------|------|
| 한국어 정확도 | **91.4%** |
| CER (Character Error Rate) | 0.1330 |
| WER (Word Error Rate) | 0.0966 |
| 처리 속도 | **1.80초/페이지** 🚀 |

---

### 3.4 pytesseract (Tesseract OCR) ⚠️ 권장하지 않음

**개요**:
- Google이 개발한 오픈소스 OCR 엔진
- 100개 이상 언어 지원 (한국어 포함)

**장점**:
- ✅ 완전 무료 (오픈소스)
- ✅ 인터넷 연결 불필요

**단점**:
- ❌ **한국어 정확도 매우 낮음** (테스트 결과 22.9%)
- ❌ 복잡한 레이아웃 처리 어려움
- ❌ 이미지 품질에 매우 민감

**실제 테스트 성능**:
| 지표 | 결과 |
|------|------|
| 한국어 정확도 | **22.9%** ⚠️ |
| CER (Character Error Rate) | 0.7711 |
| WER (Word Error Rate) | 0.6981 |
| 처리 속도 | 2.28초/페이지 (CPU) |

> ⚠️ **결론**: 한국어 문서에는 **단독 사용 부적합**. 영문 전용으로만 권장.

### 정확도 순위

```

 1위: Gemini VLM (0.0816) - 문맥 보정으로 전체 텍스트 최고
 2위: EasyOCR (0.1330) - 무료 중 최고
 3위: CLOVA OCR (0.3047) - 한글은 최고지만 영문/특수문자 포함 시 낮음
 탈락: pytesseract (0.7711) - 사용 불가

 한글정확도 기준 - 한국어만 추출하여 측정
 1위: CLOVA OCR (98.6%) - 한국어 특화, Hallucination 없음
 2위: Gemini VLM (97.4%) - 문맥 보정, 가끔 창작 위험
 3위: EasyOCR (91.4%) - 무료, 속도 빠름
 탈락: pytesseract (22.9%) - 사용 불가
```

### 결론: CER vs 한글정확도

| 지표 | 의미 | 1위 | 권장 상황 |
|------|------|-----|----------|
| **CER** | 전체 문자 정확도 (영문+한글+특수문자) | Gemini VLM | 일반 문서, 요약 필요 시 |
| **한글정확도** | 한글만 추출하여 측정 | CLOVA OCR | 금융/법률, 숫자 정확도 중요 시 |

## 5. 비용 및 속도 분석

### 월간 예상 사용량

```
문서 유형별 평균 페이지 수:
- 이력서: 1~3 페이지 (평균 2페이지)
- 포트폴리오: 10~30 페이지 (평균 20페이지)
- 채용공고: 1~2 페이지 (평균 1페이지)
```

- 이력서 OCR: 300건/월 × 2페이지 = **600 페이지**
- 포트폴리오 OCR: 200건/월 × 20페이지 = **4,000 페이지**
- 채용공고 OCR: 300건/월 × 1페이지 = **300 페이지**
- **총 페이지**: **4,900 페이지/월**

### 비용 비교

| OCR 엔진 | 비용 모델 | 월간 비용 (4,900 페이지) | 비고 |
|---------|----------|------------------------|------|
| **EasyOCR** | 무료 | **$0** | ✅ 대량 처리 권장 |
| **Gemini 3.0 Flash** | $2/M 입력, $12/M 출력 | **~$4/월** | ✅ 한도 없음 |
| pytesseract | 무료 | $0 | ❌ 정확도 낮음 |
| **CLOVA OCR** | 100건 무료 + 3원/건 | **~$12** | 고정확도 필요시 |

### 속도 비교

| OCR 엔진 | 처리 속도 | 20페이지 PDF | 순위 |
|---------|----------|--------------|------|
| **EasyOCR** | **1.80초/페이지** | **~36초** | 1위 |
| pytesseract | 2.28초/페이지 | ~46초 | 2위 |
| **CLOVA OCR** | 3.13초/페이지 | ~63초 | 3위 |
| **Gemini VLM** | 3.89초/페이지 | ~78초 | 4위 |

### Gemini 3.0 Flash 비용 분석

```
일일 한도: 1,500 요청/일

시나리오 1: 이력서 (2페이지) 중심 (채택)
  → 1,500 / 2 = 750건/일 처리 가능 

시나리오 2: 포트폴리오 (20페이지) 중심
  → 1,500 / 20 = 75건/일 처리 가능 

시나리오 3: 혼합 (이력서 300 + 포트폴리오 200)
  → 600 + 4,000 = 4,600 요청/일 필요
  → 한도 초과! Fallback 필요 
```
