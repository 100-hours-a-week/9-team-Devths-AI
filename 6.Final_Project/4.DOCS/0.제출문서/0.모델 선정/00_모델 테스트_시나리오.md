# 모델 테스트 시나리오

## 목표
- 핵심 AI 기능(채팅, 면접 Q&A, 채용공고 분석, 이력서/포트폴리오 분석, 면접 리포트)의 모델 성능을 한국어 중심으로 평가
- Gemini Flash/Pro 선택 근거를 강화하고, 대체 모델(EXAONE 등)과 비교
- 평가 지표와 테스트 데이터 명시, 중복 없이 간결하게 정리

## 평가 시나리오
| 기능 | 테스트 항목 | 테스트 데이터 | 평가 지표 |
|------|------------|--------------|----------|
| **채팅** | 일반 대화 20개, 취업 상담 10개 | 한국어 프롬프트 CSV (`chat_test_cases.csv`) | BLEU, ROUGE‑L, 응답 시간(TTFT), 비용/1M 토큰 |
| **면접 Q&A** | 기술·인성 질문 15개 | 면접 질문/답변 세트 (`interview_qa.json`) | 정확도, 질문 품질(4.5+), 응답 길이, 비용 |
| **채용공고 분석** | 10개 실제 공고 텍스트 | `job_postings.txt` | 핵심 키워드 추출 정확도, 벡터화 품질, 비용 |
| **이력서/포트폴리오 분석** | 12개 이력서·포트폴리오 (다양한 포맷) | `resumes/` 디렉터리 | 매칭 점수, 한국어 자연스러움, 처리 시간 |
| **면접 리포트** | 면접 전체 흐름 5세트 | `interview_sessions/` | 리포트 구조 정확도, 요약 품질, 비용 |

## 평가 방법
1. **자동 스크립트** (`eval/run_evaluation.py`) 로 각 CSV/JSON 를 모델 API에 호출
2. 결과를 `results/` 디렉터리에 저장하고 `markdownlint` 로 포맷 검증
3. 지표 계산 후 표에 요약 삽입
