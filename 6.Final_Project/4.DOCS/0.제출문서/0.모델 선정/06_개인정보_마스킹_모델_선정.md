## 1. 개요

### 목적
이력서/포트폴리오에서 개인정보를 자동 감지하고 마스킹 처리

### 사용 사례
- 이력서 공유 전 개인정보 마스킹
- 포트폴리오 게시판 첨부파일 자동 마스킹
- 모의 면접 시 개인정보 보호

## 4. 후보 모델 비교

### 4.1 얼굴 감지

#### Gemini Vision ✅ 선정

**장점**:
- ✅ 높은 정확도 (93%)
- ✅ Bounding Box 좌표 반환
- ✅ 다양한 각도/크기 얼굴 감지

**단점**:
- ❌ API 호출 비용

**비용**: $0.0025/이미지

---

#### OpenCV Haar Cascade (Fallback)

**장점**:
- ✅ 무료 (오픈소스)
- ✅ 로컬 실행 (빠름)

**단점**:
- ❌ 정확도 낮음 (82%)
- ❌ 각도/크기 변화에 민감

**용도**: Gemini Vision 실패 시 Fallback

---

#### YOLOv8-face (고려 대상)

**장점**:
- ✅ 높은 정확도 (96%)
- ✅ 빠른 처리 속도

**단점**:
- ❌ GPU 필요
- ❌ 모델 로딩 시간

**용도**: V2+ GPU 서버 도입 시 검토

---

### 4.2 텍스트 PII 감지

#### Chandra OCR ✅ 선정

**개요**:
- datalab-to/chandra 모델
- 한국어 PII 감지 특화

**장점**:
- ✅ 한국어 PII 감지 우수
- ✅ 다양한 엔티티 지원

**단점**:
- ❌ 모델 로딩 필요

---

#### Regex 패턴 매칭 ✅ 보조

**장점**:
- ✅ 빠른 처리
- ✅ 정확한 패턴 매칭 (전화번호, 이메일)

**단점**:
- ❌ 이름 등 비정형 데이터 감지 어려움

**용도**: Chandra와 함께 사용 (Hybrid)

---

#### Microsoft Presidio (고려 대상)

**장점**:
- ✅ 다양한 언어 지원
- ✅ 커스터마이징 가능

**단점**:
- ❌ 한국어 지원 제한적
- ❌ 추가 NER 모델 필요

**용도**: 영어 문서 처리 시 사용

## 5. 최종 선정

### 선정 전략: 하이브리드

| 유형 | 1차 | 2차 (Fallback) |
|------|-----|---------------|
| **얼굴 감지** | Gemini Vision | OpenCV Haar Cascade |
| **텍스트 PII** | Chandra OCR | Regex 패턴 |

### 비용 절감 전략

```
포트폴리오 마스킹 전략:
- 첫 페이지만 마스킹 처리 (얼굴 사진 + 연락처가 주로 있음)
- 나머지 페이지는 원본 유지

비용 계산:
- 기존: 20페이지 × $0.0025 = $0.05/건
- 최적화: 1페이지 × $0.0025 = $0.0025/건
- 절감률: 95%
```

### 마스킹 파이프라인

```
[문서 입력]
    │
    ▼
[첫 페이지 추출]
    │
    ├── [얼굴 감지] (Gemini Vision)
    │   └── 감지 실패 시 → OpenCV Haar Cascade
    │
    └── [텍스트 PII 감지] (Chandra OCR + Regex)
    │
    ▼
[마스킹 처리]
    ├── 얼굴: 원형 블러
    └── 텍스트: 블록 마스킹
    │
    ▼
[결과 반환]
    ├── 마스킹된 이미지
    └── 감지된 PII 목록
```

## 6. 구현 참조

### 코드 파일
- `3.model/app/services/gemini_masking.py` - 얼굴 마스킹 (Gemini Vision)
- `3.model/app/services/chandra_masking.py` - 텍스트 PII 마스킹

### API 엔드포인트
- `POST /ai/masking/draft` - 자동 마스킹 (비동기)

### 사용 예시

```python
# 요청
{
    "file_url": "https://storage.example.com/resume.pdf",
    "file_type": "pdf"
}

# 응답 (비동기)
{
    "task_id": "task_abc123",
    "status": "processing"
}

# 결과 조회
{
    "status": "completed",
    "result": {
        "masked_image_url": "https://...",
        "detected_pii": {
            "faces": 1,
            "names": ["홍길동"],
            "phones": ["010-1234-5678"],
            "emails": ["hong@email.com"]
        }
    }
}
```
