## 3. 후보 도구 비교

### 3.1 Langfuse ✅ 선정

**개요**:
- 오픈소스 LLM 관찰성 플랫폼
- Self-hosted 가능

**장점**:
- ✅ 무료 (오픈소스, self-hosted)
- ✅ 프롬프트 버전 관리
- ✅ LLM 호출 추적 (Trace, Generation)
- ✅ 대시보드 제공
- ✅ Python SDK 제공
- ✅ 데이터 자체 보유

**단점**:
- ❌ Self-hosted 시 인프라 관리 필요
- ❌ LangSmith 대비 기능 제한적

**비용**: 무료 (self-hosted)

---

### 3.2 LangSmith

**개요**:
- LangChain 공식 LLM 관찰성 플랫폼

**장점**:
- ✅ LangChain 완벽 통합
- ✅ 풍부한 기능
- ✅ 프롬프트 허브

**단점**:
- ❌ 유료 ($39/월~)
- ❌ 클라우드 전용 (데이터 외부 저장)
- ❌ LangChain 의존

**비용**: $39/월 (Plus), $199/월 (Team)

## 5. 주요 기능 활용

### 5.1 LLM 호출 추적 (Trace)

```python
from langfuse import Langfuse

langfuse = Langfuse(
    public_key="pk_...",
    secret_key="sk_...",
    host="http://localhost:3000"
)

# Trace 생성
trace = langfuse.trace(
    name="chat_response",
    user_id="user_123",
    metadata={"mode": "general"}
)

# Generation 기록
generation = trace.generation(
    name="gemini_response",
    model="gemini-1.5-flash",
    input={"prompt": user_message},
    output={"response": llm_response},
    usage={
        "input_tokens": 100,
        "output_tokens": 200
    }
)
```

### 5.2 프롬프트 버전 관리

```python
# 프롬프트 가져오기
prompt = langfuse.get_prompt("resume_analysis", version=2)

# 프롬프트 컴파일
compiled_prompt = prompt.compile(
    resume=resume_text,
    job_posting=job_posting_text
)

# LLM 호출
response = llm.generate(compiled_prompt)

# 프롬프트 사용 기록
trace.generation(
    prompt=prompt,
    output=response
)
```

## 6. 구현 참조

### 코드 파일
- `3.model/app/utils/langfuse_client.py` - Langfuse 클라이언트

### 현재 구현

```python
from langfuse import Langfuse

class LangfuseClient:
    def __init__(self):
        self.langfuse = Langfuse(
            public_key=os.getenv("LANGFUSE_PUBLIC_KEY"),
            secret_key=os.getenv("LANGFUSE_SECRET_KEY"),
            host=os.getenv("LANGFUSE_HOST", "http://localhost:3000")
        )

    def trace_llm_call(
        self,
        name: str,
        user_id: str,
        model: str,
        input_text: str,
        output_text: str,
        metadata: dict = None
    ):
        """LLM 호출 추적"""
        trace = self.langfuse.trace(
            name=name,
            user_id=user_id,
            metadata=metadata
        )

        trace.generation(
            name=f"{model}_generation",
            model=model,
            input=input_text[:4000],  # 길이 제한
            output=output_text[:4000]
        )
```
