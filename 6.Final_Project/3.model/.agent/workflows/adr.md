## 파일 규칙: 한 파일에 5개 ADR

- **그룹 파일명 형식**: `[AI] {NN}_ADR_ {XXX}-{YYY}.md`
  - `NN`: 그룹 순번 (00, 01, 02, …), 2자리 제로패딩
  - `XXX-YYY`: 해당 파일에 담긴 ADR 번호 범위 (예: 046-050, 051-055)
- **한 파일에는 반드시 5개의 ADR**을 담는다
- **다음 그룹 파일 생성 시점**: 현재 그룹 파일에 5개 ADR이 모두 작성된 경우에만 새 파일 생성

## 실행 순서

// turbo
1. **대상 파일 결정**
   - `4.DOCS/1.ADR/` 아래 `[AI] *_ADR_ *.md` 파일 나열

3. **사용자와 내용 구체화**

## 작성 규칙

- 모든 내용은 **한국어**
- 최소 **2개 이상 선택지** 비교 분석
- **코드 스니펫** 또는 아키텍처 다이어그램 포함
- 관련 기존 ADR이 있으면 **참조/링크** 추가
- 프로젝트 실제 코드 경로·패턴 반영 (예: `app/services/`, `3.model/` 등)

## 인수

사용자가 ADR 번호 + 제목을 제공 (예: `051 Redis 세션 TTL 전략`)
