# PR 리뷰 코멘트 생성기

## 대상 결정

- 사용자 인수가 숫자면 PR 번호로 `gh pr diff <PR번호>` 후 diff 기반 코멘트 생성
- 인수 없으면 현재 브랜치와 base(develop 등)의 diff로 코멘트 초안 생성

## 실행 순서

// turbo
1. **diff 수집**
   - `gh pr diff <PR번호>` 또는 `git diff <base>...HEAD`
   - 변경된 파일 목록 및 라인 단위 변경 확인

2. **코멘트 초안 생성**
   - 파일·라인별로 개선 제안, 버그 가능성, 스타일 제안을 짧은 코멘트로 작성
   - 인라인: 해당 코드 라인 바로 아래 제안
   - 일반: 파일/PR 전체에 대한 요약 코멘트
   - **보안 중점 확인:**
     - `request.*` 속성이 `logger.*()` 에 들어가는 Log Injection 패턴
     - `asyncio.create_task()`의 생명주기 (SSE generator 내부 사용 시 주의)
     - ChromaDB `add()` vs `upsert()` 중복 ID 처리

3. **출력 형식**

```markdown
## PR 리뷰 코멘트 초안

### 파일: `경로/파일명`
- **L{라인}**: [제안] 한 줄 설명
- **L{라인}**: [주의] 한 줄 설명

### 전체 코멘트 (PR 본문용)
- 요약 1
- 요약 2
```

## 규칙

- 코멘트는 짧고 실행 가능하게 (한국어)
- `gh pr review <PR번호> --comment -b "내용"` 또는 인라인은 `gh api`로 제출 가능하다는 점 안내
- 사용자에게 초안을 보여준 뒤 제출 여부 확인
- `/commit`, `/pr`과 배치 호출 시 PR 번호를 자동으로 사용 (별도 입력 불필요)
